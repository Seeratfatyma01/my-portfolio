# Seerat Fatima — AI Student Portfolio

A responsive personal portfolio built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling
- `script.js` — mobile navigation and footer year

## Before publishing
1. Confirm your name, program, semester, and session.
2. Replace `your.email@example.com` with your real email.
3. Replace the sample GitHub and LinkedIn links with your own profiles.
4. Edit the project descriptions so they accurately describe your work.
5. Update the skills to reflect your actual experience.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `my-portfolio`.
2. Upload all three website files (`index.html`, `style.css`, `script.js`) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for the deployment to finish. Your site URL will appear in the Pages section.

You can also deploy this folder through Vercel by importing its GitHub repository.
